# Visión del proyecto

Zynervox es una interfaz de call center sobre Asterisk/VICIdial. Gestiona usuarios,
agentes, campañas, listas, carriers, monitoreo, reportes y flujos Bot IVR. La web es
PHP/JavaScript, los workers IVR son Python y los datos operativos viven en MariaDB.

Este repositorio es una distribución sanitizada: no contiene datos, contraseñas,
tokens, grabaciones, audios generados ni configuración privada de producción.
